## Overview

Simagic SimPro Profiles is a profile management companion for Simagic SimPro steering wheels, allowing drivers to save, load, and share FFB (force feedback) profiles optimized for different games and tracks. It exports and imports the SimPro Manager's full profile format, making it easy to apply community-shared setups.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Simagic SimPro Profiles** delivers the features you need in a clean, intuitive package.

> Official website: [simagic.com](https://simagic.com)

## Key Features

| Feature | Description |
|---------|-------------|
| **Profile Save/Load** | Save and load FFB profiles for any Simagic SimPro wheel model |
| **Community Import** | Import community-shared profiles with one file drag-and-drop |
| **Game Presets** | Organize profiles by game title for quick pre-session switching |
| **FFB Preview** | Visualizes the force curve and peak force values of each profile |
